# Phylactery 分卷

把一个文件夹**双层加密**并切成若干分卷，方便放进网盘；下载回来后核对、解密、还原。
有 Windows 程序和飞牛 fnOS 应用两个版本，哪一端打的包，两端都能解开。

> Phylactery：希腊语“护身之物”。奇幻故事里，巫妖把灵魂封进命匣藏起来——这里封的是你的文件。

本仓库只发布安装包，不含源码。下载见右侧 **Releases**。

## 下载

| 文件 | 用途 |
|---|---|
| `Phylactery-Setup-<版本>.exe` | Windows 10 / 11（64 位）安装包 |
| `phylactery-<版本>.fpk` | 飞牛 fnOS 应用包（x86） |
| `SHA256SUMS.txt` | 两个文件的 SHA-256，下载后可以核对 |

## 它怎么保护你的文件

**网盘上只有密文**
- 第一层：7-Zip AES-256，连文件名一起加密；每一批用你打包时输入的“打包密码”。
- 第二层：age（X25519）逐卷再加密一次，钥匙是 256 位随机数，只存在你的“库”里，没法猜。
- 只拿到网盘上的分卷，什么也解不开。

**库（密码本）用你的口令锁着**
- 库里放着钥匙、每一批的打包密码和批次记录，整个用口令加密（scrypt，每试一次约 512 MB 内存、1 秒）。
- 口令至少 12 位（或 16 位以上），太弱的会被拒绝；可以一键生成 20 位随机口令。

**在程序里猜口令行不通**
- 连续输错 3 次，进入一个看起来正常、其实是空的“虚假库”，什么都做不了。
- 24 小时内第 3 次进入虚假库，开始冷却：1 天、7 天、30 天、90 天，按程序自己的运行时间计算，改系统时间没用。冷却期间输对口令也不放行。
- 建库时给你一个**恢复码**：只能用来解除冷却，不能打开库。请抄在纸上。
- 正式版没有命令行模式，没法用脚本绕过界面。

**离开电脑也不怕**
- 查看或复制打包密码、导出同步文件、删除、改设置，都要再输一次口令；连续输错 3 次直接锁库。
- Windows 版空闲 15 分钟自动锁定；复制的打包密码 30 秒后从剪贴板清掉。

## 主要功能

- **分卷目标值**：填想分成几卷，程序按文件总量算出每卷多大并预览（每卷超过 4 GB 会提醒）。
- **断点续跑**：打包、解密中途关机也能继续。
- **解密前核对**：分卷是否齐全、是否还在下载；解密后核对文件数和字节数；同名文件不覆盖。
- **同步文件**：把一端的钥匙和打包密码带到另一端，同时也是库的备份。
- **自动发现**（NAS 版）：监视下载目录，分卷到齐后自动解密或等你确认。
- **删除**：删解密出来的文件、删一批的记录、删整个库，都要口令。
- **本地分卷到期自动删除**：每个库单独设定（关闭 / 3 天 / 7 天 / 1 个月 / 3 个月 / 1 年），从打包完成时起算。

## 安装

**Windows**：双击安装包。装好后第一次打开，选一个位置新建“库”。

**飞牛 fnOS**：应用中心 → 手动安装 → 选 `.fpk` 文件。只有管理员能使用。
应用以自己的账号运行，要访问你的文件夹，请在“应用设置 → 授权目录”里把要用的文件夹授权给它。

## 最重要的三件事

1. 口令忘了，库就打不开。请另外记好。
2. 库丢了，只能靠同步文件恢复。有新批次时导出一份同步文件，离线保存。
3. 程序不会删除你的源文件；会真正删除的只有你输了口令确认的那几项。
